# Musiq (موزیک)

پخش‌کننده و مدیر کتابخانه‌ی موسیقی برای اندروید، با Kotlin و Jetpack Compose. موسیقی روی دستگاه را پخش و مرتب
می‌کند، تگ و کاور و متن آهنگ را درست می‌کند و می‌تواند موسیقی **رایگان و قانونی** را از چند منبع آزاد دانلود کند.
فارسی (راست‌به‌چپ) و انگلیسی کامل پشتیبانی می‌شوند. توضیح کامل‌تر به انگلیسی در [README.md](README.md) است.

## امکانات

* **کتابخانه:** اسکن پس‌زمینه، آهنگ‌ها، هنرمندان، آلبوم‌ها، ژانرها، پوشه‌ها، پلی‌لیست‌ها؛ فهرست یا شبکه‌ای؛ جستجو و انتخاب چندتایی.
* **خانه:** بخش‌های قابل تنظیم و قابل جابه‌جایی (اخیراً پخش‌شده، پرپخش‌ترین‌ها، علاقه‌مندی‌ها، پلی‌لیست‌ها و …).
* **پخش‌کننده:** Media3 با اعلان، Lock Screen، Bluetooth، صف، تایمر خواب، سرعت پخش و متن همگام.
* **تگ‌ها:** خواندن و نوشتن با TagLib، ویرایش گروهی؛ هر نوشتن پشتیبان‌گیری، بررسی و در صورت خطا بازگردانی می‌شود.
* **کاور و متن آهنگ:** MusicBrainz / Cover Art Archive و LRCLIB، وارد کردن `.lrc`، جاسازی در فایل.
* **جستجوی سراسری** و **سلامت کتابخانه** (کاور/متن/تگ ناقص، کیفیت پایین، آهنگ‌های تکراری با حذف تأییدشده).
* **پلی‌لیست عادی و هوشمند** (اخیراً اضافه‌شده، پرپخش‌ترین، هرگز پخش‌نشده، علاقه‌مندی، ژانر، فارسی، کیفیت بالا، بلندتر از N دقیقه).
* **دانلود قانونی:** Internet Archive، Openverse، Wikimedia Commons، ccMixter، Jamendo، لینک مستقیم https و فید RSS؛ با ادامه‌ی دانلود.
* **شخصی‌سازی:** تم، رنگ، گردی گوشه‌ها، اندازه‌ی متن، انیمیشن، چیدمان، ترتیب تب‌ها و بخش‌های خانه، تغییر زبان داخل برنامه.

## ساخت

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew assembleRelease
```

لازم نیست روی کامپیوتر خودتان بسازید: GitHub Actions با هر push کد را تست می‌کند و APK دیباگ را به‌عنوان Artifact می‌گذارد.
با ساختن تگ `v*` یک APK امضاشده‌ی Release در بخش Releases منتشر می‌شود.

## امضا

* APK دیباگ با کلید عمومیِ `app/debug.keystore` امضا می‌شود تا هر نسخه روی قبلی نصب شود. هرگز آن را برای انتشار استفاده نکنید.
* APK ریلیز با کلید محرمانه‌ای امضا می‌شود که فقط در **GitHub Secrets** است (`RELEASE_KEYSTORE_BASE64`، `RELEASE_KEYSTORE_PASSWORD`،
  `RELEASE_KEY_ALIAS`، `RELEASE_KEY_PASSWORD`). **از فایل کلید حتماً نسخه‌ی پشتیبان نگه دارید.** بدون آن هرگز نمی‌توانید نسخه‌ی به‌روزرسانی بدهید.
* امضای ریلیز با دیباگ فرق دارد؛ برای رفتن از یکی به دیگری یک‌بار باید برنامه را حذف کنید.

## حریم خصوصی

حساب کاربری، ردیابی و تبلیغ وجود ندارد و کتابخانه از دستگاه خارج نمی‌شود. اینترنت فقط هنگام جستجوی کاور، متن و دانلود و فقط
با https استفاده می‌شود. هیچ فایلی بدون تأیید شما حذف یا بدون پشتیبان تغییر نمی‌کند.

## دانلود و قانون

فقط منابعی ارائه می‌شوند که محتوایشان مجوز آزاد دارد، در مالکیت عمومی است یا هنرمند اجازه داده؛ مجوز هر آهنگ نشان داده می‌شود.
رعایت مجوز (مثلاً ذکر نام هنرمند) با خود شماست. گزینه‌های «لینک مستقیم» و «فید RSS» هر چه را که نشان دهید دانلود می‌کنند؛ فقط برای
فایل‌هایی استفاده کنید که حق دانلودشان را دارید.

## محدودیت‌های شناخته‌شده

Android Auto، تم پویا از رنگ کاور و Blur، Paging 3، بخش «Recommended»، اثر انگشت صوتی و تشخیص خودکار آهنگ (Identify Song) هنوز
پیاده‌سازی نشده‌اند. منبع‌های آنلاین فقط با داده‌ی نمونه تست شده‌اند. تست روی دستگاه (Instrumented) وجود ندارد.

## تغییر نام برنامه

نام نمایشی در `app_name` داخل `values/strings.xml` و `values-fa/strings.xml` است. `applicationId` را تغییر ندهید، وگرنه اندروید آن را
برنامه‌ی دیگری می‌داند.
